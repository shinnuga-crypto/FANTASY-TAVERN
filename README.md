# FANTASY TAVERN / ミレーネの酒場

ファンタジー酒場を舞台にした、周回型の給仕アクションゲーム。修道女兼給仕のミレーネを操作し、注文・配膳・片付け・トラブル対応をこなしながら教会の復興を目指します。

## ダウンロードと起動

1. [試遊版のダウンロードはこちら](https://github.com/shinnuga-crypto/FANTASY-TAVERN/releases)。
2. 最新リリースの ZIP をすべて展開してください。
3. `MileneTavern.exe` をダブルクリックします。

Windows 64-bit向け・日本語。Godotのインストールやインターネット接続は不要です。画像・BGMをゲーム本体に内蔵しています。

## 操作

- 左クリック：移動・仕事を順に予約
- Ctrl＋クリック：予約へ割り込み
- 右クリック／Esc：予約を中断
- 会話中は画面をクリックして読み進め、選択肢はボタンを選びます。
- Q／E／C／F：対応する技能の習得後に能力を使います。

## セーブ

周回・成長・所持金・教会復興・営業途中・会話途中の状態を自動保存します。終了後はタイトルの「続きから」で再開できます。タイトルのリセットからセーブを削除して最初から遊べます。セーブはWindowsのユーザーデータ領域に保存され、ZIPには含まれません。

## この配布について

開発中の試遊版です。今後の更新で内容やバランスが変わることがあります。不具合は [Issues](https://github.com/shinnuga-crypto/FANTASY-TAVERN/issues) へ、発生した場面と操作を添えて報告してください。

配布ZIPにはゲーム本体、起動説明、Godotと関連ライブラリのライセンス表記を含みます。Godotのライセンス表記は、ゲームの画像・音楽などの素材を再配布する許可ではありません。
